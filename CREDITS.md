# Credits

The 29 super-skills in this kit combine skills written by many other people. Those skill files are **not stored in this repository**.
The installer downloads them from their authors' public GitHub repositories onto your own computer, at a fixed version, so you get them straight from the source.
Each project keeps its own license; please read it before reusing its files elsewhere.
